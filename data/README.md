# Data directory

| Folder | Content | Tracked in git |
|---|---|---|
| `raw/` | Ingested input as collected (`transactions_raw.csv`, `security_events_raw.csv`) - includes injected defects | no |
| `synthetic/` | Output of the seeded generators (Parquet) and small `sample_*.csv` heads | samples only |
| `interim/` | Cleaned transactions (`transactions_clean.parquet/.csv`) | no |
| `processed/` | Model-ready features + split labels, scored security events, trust scores | no |
| `external/` | Optional public datasets (not redistributed) | no |

Everything except the samples is re-created by `make pipeline` / `docker compose up`.

## Synthetic datasets (default)

Generated by `src/data_collection/synthetic.py` from `seed` in `config/settings.yaml` (see
[documentation/dataset_description.md](../documentation/dataset_description.md) for the data dictionary).
Same seed + same `end_date` ⇒ identical files. `end_date: auto` anchors the 90-day window to the run date so Grafana
time filters show data; set a fixed ISO date for bit-for-bit reproducibility.

## Optional public benchmark: ULB / Worldline credit-card fraud

1. Download `creditcard.csv` from <https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud> (Database Contents License;
   cite Dal Pozzolo et al., 2015 - see `report/references.bib`).
2. Place it at `data/external/creditcard.csv`.
3. Run the pipeline. An `external_benchmark` stage trains the same models chronologically and writes
   `report/tables/external_benchmark_creditcard.csv`.

Use only datasets whose licence permits your use, and never commit them.
